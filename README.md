# 🇮🇳 India Air Quality Dashboard

An interactive data analysis dashboard analyzing real AQI data 
across major Indian cities.

## 📊 Key Findings
- **Ahmedabad** is India's most polluted city on average
- **November** records highest AQI due to Diwali and crop burning
- AQI has been **decreasing yearly** showing impact of pollution policies
- Analysis based on **29,531 real records** across Indian cities

## 🛠️ Tools & Technologies
- Python, Pandas — data cleaning & analysis
- Streamlit — interactive dashboard
- Matplotlib — visualizations

## 📁 Files
- `app.py` — Streamlit dashboard code
- `India_AQI_Analysis.ipynb` — Full analysis notebook

## 🚀 How to Run
pip install pandas streamlit matplotlib
streamlit run app.py

## 📥 Dataset
Download `city_day.csv` from [Kaggle - India Air Quality Data]
(https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india)
and place it in the same folder as `app.py`
